# Fachwerk: Your folders, always within reach

Fachwerk keeps the folders you choose in the VS Code sidebar, across every workspace. Pin shared notes, documentation, templates, or any directory you use often.

Choose several folders at once, or add one directly from Explorer. Each gets a collapsible section with its directory tree. Open files with a click, copy their content or paths, and remove pins without deleting anything.

New installations start with your choices. Existing users keep their folder pins and can preserve earlier Agents, Skills, and Instructions panels as ordinary saved sections.

Find **Fachwerk** by **gundurraga** on the VS Code Marketplace.

Source: https://github.com/paintingstack/fachwerk

Fachwerk is German for timber framing, the visible structure that holds a building together.
